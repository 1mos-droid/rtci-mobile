# Design and release documentation

The maintained design direction, library assessment, and visual review commands are in [DESIGN.md](DESIGN.md).

The current implementation and outstanding production requirements are tracked in [RELEASE_READINESS.md](RELEASE_READINESS.md). Follow [BACKEND_ROLLOUT.md](BACKEND_ROLLOUT.md) for the coordinated backend and app rollout.

The redesign includes warm ivory and burgundy surfaces, bundled Inter typography, responsive layouts and navigation, a custom reduced-motion-aware seal loader, and native accessible controls. No React runtime or component collection is embedded in the Flutter application.
